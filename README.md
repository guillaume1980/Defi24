# Défi24 — MVP

Première base du MVP Défi24, construite pour démarrer sans backend payant.

## Inclus
- Défis de 24 h
- Dooffy, mascotte IA
- Onboarding et personnalisation par univers
- XP, niveaux et séries
- Validation du défi
- Preuve et feed UGC local
- Réactions et partage via les fonctions du téléphone
- Création de défis
- Mode anti-scroll
- Sauvegarde locale avec `localStorage`
- Interface mobile-first

## Lancer
Ouvrir `index.html` dans un navigateur.

## Prochaine évolution
Backend sécurisé, comptes utilisateurs, vraie base de données, modération serveur, notifications push, IA Dooffy connectée et système de défis communautaires à grande échelle.
